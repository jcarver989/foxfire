Show the user something you made, inline in the conversation.

Write it to a file first, then submit it. It is shown where the user is, which may be a different machine from yours, so it must stand alone: an HTML page must inline its styles, scripts and images, and not refer to other local files.

The file is read and copied when you submit it. To show a change, edit the file and submit it again: the next version takes the place of the one the user was shown.
